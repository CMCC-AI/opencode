# AI for Science 科研工作台

## 产品定位与能力拆解

把“选择专家团”转化为“选择要完成的科研工作”。保留首席科研专家阿顾作为统一编排入口，20 位成员按需参与。用户面对的是目标、输入、交付物，不需要了解 Agent ID 或内部任务 DAG。

现有专家团原生支持从 Idea、综述、复现、实验、写作或审稿任意位置接管，已有 G1-G4 确认、证据登记和研究包归档能力。工作台不另建一套执行引擎，而以独立能力契约组织现有对话。

| 产品能力 | 输入 | 核心专家 | 交付 |
| --- | --- | --- | --- |
| DeepXiv 论文发现 | 研究兴趣或检索方向 | 现有嵌入应用 | 论文线索、阅读入口 |
| 论文综述 | 主题、时间范围、种子论文 | 检索策略、论文发现、证据分析、研究综合 | 文献矩阵、方法脉络、研究空白 |
| 论文复现 | 论文、仓库、数据、算力 | 证据分析、代码工程、实验执行、结果分析 | 复现代码、运行记录、原文指标对比 |
| 实验设计 | 假设、数据与资源约束 | 可行性、方法论、实验设计 | 对照与消融方案、指标与成功标准 |
| 实验执行 | 已确认方案、代码、数据和环境 | 工程、执行、诊断、分析 | 真实日志、结果图表与统计结论 |
| 论文撰写 | 已有结果、证据、草稿、目标期刊 | 大纲、写作、图表引用编辑 | 论文草稿、图表说明、参考文献 |
| 模拟审稿 | 稿件、补充材料、目标期刊 | 独立审稿、引用审计 | 分级问题、审稿意见、修订清单 |

资产盘点、需求识别、可行性判断和归档是跨环节基础能力，由主理人按需调用，避免首页出现过多技术性卡片。数据分析当前包含在实验执行中，可在下一阶段扩展为独立产品入口。

## 信息架构与视觉

新增主导航 `AI for Science` → `/ai-for-science`。保留原有产业洞察、DeepXiv 等入口，科研工作台中提供 DeepXiv 的快捷入口，复用原有 iframe 与登录机制。

布局由四个层次组成：

1. 深蓝研究主题区：展示产品定位，以抽象轨道表达探索、证据与洞察。
2. 研究路径带：发现文献 → 形成假设 → 实验验证 → 论证写作 → 审查交付。它表达研究关系，不是假装正在运行的进度条。
3. 能力目录：DeepXiv 横向入口 + 六张可选择的能力卡；按发现、验证、表达筛选。
4. 任务配置栏：选择模式、查看输入和专家、填写需求与材料、进入科研对话。桌面右侧吸附，窄屏排列至目录下方。

使用纸白背景、深海蓝主题区、青绿选择态；较低饱和度配色、清晰留白与中英双层标题兼顾专业感和可读性。卡片说明“完成什么、交付什么”，专家分工在选中后呈现。

设计参考 Elicit 将文献综述拆成检索、筛选、提取等明确阶段的工作流表达：https://elicit.com/blog/systematic-review 。本方案将这种阶段与交付物的表达扩展至完整科研链路。

## 交互与执行边界

独立环节：选卡片 → 查看输入提示 → 填写研究需求和已有材料 → 进入可编辑对话草稿。提示词明确只完成选定目标，不自动扩展到全流程；必要的证据审计和独立核验仍保留。

串联流程：切换模式 → 点击卡片选择或移除环节 → 查看有序路径 → 填写共享需求与材料 → 进入同一科研对话。沿路径复用上一阶段已核验产物，执行仍由现有主理人根据资源与确认状态编排。

推荐组合：

- 选题到论文：综述 → 实验设计 → 实验执行 → 撰写 → 模拟审稿。
- 复现研究：论文复现 → 撰写 → 模拟审稿。
- 已有结果：撰写 → 模拟审稿。
- 投稿前检查：仅模拟审稿。

本次实现的是对话式流程编排入口，不是新增持久化的流程调度器。没有虚构运行进度、任务数、历史研究或自动执行结果。任务在草稿发送后启动，G1 范围、G2 资源权限、G3 实验方案、G4 结论发布由现有专家机制确认。

DeepXiv 是独立嵌入应用；本次未实现跨 iframe 的论文自动导入。用户可将论文链接或文件路径填写到材料框。跨产品论文篮、研究项目空间、阶段状态持久化与产物自动接续应在定义数据接口后扩展。

## 实现与验证

- `src/pages/cmcc-science.tsx`：路由入口与可独立渲染的 ScienceWorkbench 展示组件。
- `src/pages/cmcc-science.css`：限定作用域的响应式视觉样式。
- `src/utils/cmcc-science.ts`：六个能力契约与任务提示词生成。
- `src/pages/cmcc-experts.tsx`：复用现有草稿启动器，工作区未就绪时反馈错误。
- `src/app.tsx` / `src/pages/layout-new.tsx`：路由和侧栏入口。

包目录执行 `bun typecheck`；`bun test src/utils/cmcc-science.test.ts` 验证独立范围、串联产物交接、输入缺失。

正式页面需现有登录态。通过临时隔离入口渲染同一展示组件进行布局与选择交互检查，未绕过认证、未启动真实科研任务。生产登录后的草稿跳转与后端执行需在有效登录态下联调。
