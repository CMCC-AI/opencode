# 研究受阻后的自主恢复：设计依据

核查日期：2026-11-02。本文是工程设计记录，不是运行时任务答案或候选资源保证；通用流程不按题号预设数据源，也不读取隐藏评分标准。没有下载大模型、运行天气预测或重跑 Earth003，下面仅为公开资料核查。

## 从本地缺失到可执行实验

此前 benchmark 主入口限制外部获取，发现专家却被要求检索公开数据，两者不一致。现在统一为：任务未明确禁止时，默认授权为原始目标获取公开免费且无需新增凭据的资料；原任务的显式限制仍优先。公开资源运行应单独标记，不能自动声称符合封闭输入评测规则。

恢复分为缺口诊断、候选搜索、适配审计、获取与校验、真实输入最小运行、正式实验。下载是工程动作，证据是否足以支持研究问题仍需方法与科学审查。预算按机器和本轮任务制定，不给所有领域统一固定下载量或实验规模；预算耗尽意味着未完成，不意味着资源不存在。

## 官方资料核查及其设计含义

1. [FuXi 官方仓库](https://github.com/tpys/FuXi) 同时介绍旧版级联模型与新版模型，并链接 Zenodo 模型/样例资源；样例输出说明为单个 T+6，不能直接当作完整 15 天轨迹。设计含义：只检查本地样例不足以判断外部模型是否可恢复；必须核对版本、模型包和完整推理路线，不能静默替换为新版。链接存在不保证当前环境能实际获取或运行。
2. [WeatherBench 2 数据指南](https://weatherbench2.readthedocs.io/en/latest/data-guide.html) 列出公共云上的真值、气候态、预测及不同分辨率资源，同时有不同时间覆盖与数据许可。设计含义：可探索公开验证资料，但须检查有效日期、初始化、变量、分辨率、验证基准与许可；不因资源名称相似就当作可配对基线。某些列出档案不覆盖原始样例日期，不能拼接冒充同条件比较。
3. [Hugging Face Hub 下载指南](https://huggingface.co/docs/huggingface_hub/en/guides/download) 支持版本固定和按模式选择文件。[下载接口](https://huggingface.co/docs/huggingface_hub/package_reference/file_download) 还列出 dry_run 等参数。设计含义：优先元数据与必要文件再获取大资产，记录版本并复用缓存；使用时先检查安装版本是否支持所需参数。

## 职责与证据

首席专家维护计划、预算、状态、闸门及最终记录；发现专家只返回候选和获取方案；资产专家审计契约与适配；工程/执行专家按实际权限下载、运行并保存日志；可行性顾问审资源路径；独立审稿人检查替代是否仍回答原问题。Worker 不新增调度权限。

用预训练权重推理不证明自行训练成功；用公开预测评估不证明本次开发了模型；最小运行不证明统计可靠性；辅助诊断不替代原 P0。恢复失败有依据时可发布限定报告，但原目标仍 incomplete/blocked。

## 验证边界

本次改造以 agent 指令、自动闸门、启动提示及可追溯记录为主，不新增系统级下载器、硬盘配额或网络沙箱。现有测试检查配置和基础工具兼容性，不能证明 agent 在任意领域都会找到适用资源。端到端有效性需要部署后用实际有缺口的研究任务验证，检查是否形成真实获取、试运行与正式实验日志。
