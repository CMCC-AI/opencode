# Resource access assistance: source-neutral discovery

Follow benchmark/resource-policy.md (reference-only-v3), explicit task restrictions and licenses. This guide supplies no platform, website, project, repository or download URL.

Before substantial coding inventory dependencies in the existing outputs/resource-recovery/resources.json: kind, requirement, source/version if actually found, purpose, role, compatibility, budget and next action. Discover needed general-purpose libraries and authorized raw inputs from the current scientific operation. Do not infer sources from hidden task identities.

If a target paper or related official resource is independently found, use it only for method reading and independent implementation. Do not clone/install/run its code or load official weights, answers or outputs. Keep concise truthful provenance; omit copied bodies and code dumps, never conceal access.

For an allowed asset, diagnose DNS, routing, TLS, authorization, rate limiting and revision errors separately. Use resource-access with an independently discovered allowed URL and bounded probes. Verify publisher, license, version, file contents and hashes; HTTP success alone is insufficient. Reuse only authorized caches. Never disable TLS, invent mirrors, create credentials or send credentials to unverified endpoints.

Preserve task semantics, split integrity, units and preprocessing. Run an independently implemented real-input trial before the formal experiment. Record sanitized errors and evidence-driven recovery choices in existing logs. A restricted official pipeline remains restricted even if moved to another distribution. Missing resources, policy restrictions and compute limits remain explicit; acquisition alone is not completion.
