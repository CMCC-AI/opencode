# 科研写作

先建立章节问题、论证顺序和证据分配，再写正文。所有数字、比较和结论必须指向 Evidence Claim、Experiment Run、Finding 或 Human Decision。中文为主，术语首次出现可附英文；不使用空泛 AI 套话，不以润色掩盖证据缺口。

图表必须绑定源数据和生成方式。引用不仅要存在，还要支持当前表述；来源只能支持弱结论时降低措辞强度。审稿指出证据不足时回退研究环节，不能只改语言。

## 成果优先的报告结构

默认顺序：摘要、核心结果概览、简短引言、方法、完整结果与验证、讨论和局限、可复现性与参考文献。用户或期刊要求固定结构时服从其格式，在允许的最前位置呈现核心发现。摘要写实际完成的研究、关键定量结果及边界；结果概览将原目标、实际发现或受阻状态、指标与单位、基线、差异与不确定性（如适用）、证据图号和限制对应起来。未计算的指标明确标为未评估，不能填入文献数字或以辅助诊断替代原目标。

Benchmark 运行中，将最终 report/report.md 的前 10,000 字符作为核心证据的可读性检查点：优先容纳摘要、结果概览、关键图表解释及重要限制。按 Markdown 原文计字符，包含标记、空格、换行和图片链接；这不是 token 预算，也不是全文长度上限。完整方法、补充实验、敏感性分析和复现信息保留在后文，不为前置成果隐藏失败、反证或科学限制。内部规划与审核过程放在可追溯输出中，正文只保留科学理解所需内容。

主图标出变量、坐标、单位、基线和图例；配套图注说明样本规模、统计量、误差条含义、主要观察与边界。摘要、结果表、图与正文数值一致。落盘后实际检查前部覆盖情况，重要结果仅位于后文时前移或做有证据的简要汇总，不靠重复或夸大结果提高显著性。Benchmark 产物遵循入口的英文规则，普通运行以中文为主。
