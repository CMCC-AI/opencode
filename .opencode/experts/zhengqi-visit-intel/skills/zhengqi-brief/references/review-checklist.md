# 自核验清单（第6步，一次执行，不循环）

对 40-report.md 逐项检查，发现问题就地修复一次后结束，不发起多轮审稿。

## 数字核验

- [ ] 每个关键数字与 10-material-notes.md 登记原值一致：值、单位、小数位、正负号、期间、主体
- [ ] 无心算编造的差额/增幅/占比；有计算的标明了依据
- [ ] 不同口径数字没有混同（收入≠合同额≠回款≠商机额）；同一数值没有跨材料误相加
- [ ] 状态词与材料一致（已签约/在建/已验收/在谈未升级降级）

## 领导核验

- [ ] 出现的每位现任领导满足：权威公开原页正文 或 两个独立内部来源（规则见 facts-and-leaders.md）
- [ ] 不满足的已删除，不是改成模糊表述
- [ ] 职务、姓名、组织关系与来源一致，无臆测

## 分层核验

- [ ] 内部事实、公开事实、分析建议三层无混写
- [ ] 合作机会用"建议关注/可作为切入点/宜在拜访中确认"类表达，无客户承诺式断言
- [ ] 公开信息没有用来证明内部收入合同；内部记录没有用来证明公开事件

## 引用与结构

- [ ] 关键事实与数据后有 [N]，N 与文末参考文献一一对应、无缺号重号
- [ ] 参考文献不含元说明文件（README/数据字典/目录索引/免责声明类，分级见 material-reading.md）
- [ ] [N] 与文末条目双向一致：正文每个 [N] 有对应条目，每条条目在正文至少被引用一次（无悬空条目）
- [ ] 参考文献每条是真实来源（文件名/页面标题），无编造
- [ ] 篇幅达到用户要求或默认13500字以上
- [ ] 末章无已核证内容时整节已删；无"未找到"式凑数段落

## 洁净核验

- [ ] 正文无原始Prompt内容、SRC/FACT等机器编号、流程/worker/核验过程描述
- [ ] 无模型自我保证、置信度标签、待确认台账、会前会后行动清单
- [ ] 末尾声明句在位且与00-input.json的disclaimer_text一致（供渲染校验）

## 渲染预检

- [ ] 已为图表候选数据确认：真实、可比、有独立分析价值；不满足的不进61
- [ ] 40-report.md 与 60-quick-report.md 正文一致（60只多图表占位）
