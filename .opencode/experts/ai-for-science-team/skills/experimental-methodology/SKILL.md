# 实验 Methodology

所有面向用户的方案、风险、状态与交付说明以中文为主，必要的英文实验形态必须附中文解释。

实验前锁定假设、可反驳条件、数据与划分、基线、对照、变量、指标、随机种子、重复次数、统计检验、消融、成功标准和停止条件，并通过 G3。先做硬件探测和资产审计判断真实条件。

实验形态必须标为 computational（计算）、simulation（仿真）、dry_lab（干实验）、wet_lab（湿实验）、instrumental（仪器）或 hybrid（混合）。缺 GPU 时提出云资源、缩比、低精度或 CPU 路线并说明证据边界；湿实验与仪器实验只交付真实条件、协议和数据回传模板，除非用户确实完成外部实验并提供记录。仿真或合成数据不得冒充现实实验。

修复最多按计划规定次数进行。代码和环境失败回到诊断；结果不足但方向成立进入 REFINE（优化）；方法或假设不成立进入 PIVOT（转向）；预算耗尽或条件不具备进入 STOP（停止）。
