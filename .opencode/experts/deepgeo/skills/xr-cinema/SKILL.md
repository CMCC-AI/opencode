# XR Cinema Site Selection

## 目标

把位置、客群、商业和成本数据转换为 XR 影院候选点位比较、投资边界和签约前验证方案。

## 必须覆盖

- 总客流与有效停留客流；
- 年轻、亲子和娱乐客群的时段匹配；
- 地铁、公交、自驾和停车；
- 传统影院、VR/XR、电玩、密室、餐饮和亲子业态的竞争协同；
- 面积、楼层、租金、装修、设备、人工和内容更新；
- 保守、基准和乐观情景；
- 当日级历史数据足够时，对未来 4—8 周的有效停留或目标客群需求做可解释短期推演：以近期平均、同星期规律和直线趋势进行留出回测，呈现预测范围与失效条件，不把预测写成承诺；
- 盈亏平衡、静态现金流/会计回收期和亏损概率；当前 Runtime 未实现完整长期现金流、NPV/IRR，必须明确标为未计算，不得手算补齐；
- 聚合到访频次、复访占比或新老客构成可用时的客群活跃度与新鲜度分析，缺失时声明证据不足；
- 区域房价层级、消费层级与业态结构可用时的客群购买力代理评估；
- 候选商场线上运营投入度：`xr_online_presence.csv` 可用时分析公众号发文、篇均阅读、小程序月活和线上活动的投入趋势，联网授权时补充公开信号，两者皆无时写明未评估；
- 推荐、备选、不推荐及进入条件。

高客流不能自动等于优选。必须识别通勤经过客流、活动异常、高租金和场地条件等陷阱。模拟器中的结论只用于流程验收。
