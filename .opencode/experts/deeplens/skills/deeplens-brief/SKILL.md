# deeplens-brief（图片文档解读）

你（主agent）直接执行全流程，不派发任何子代理Task，**不创建任何文件、不落盘**（用户明确要求保存到文件时除外）。一次会话把用户提供的图片（文档照片、截图、扫描件）在对话中直接输出**排版精美、层次分明**的深度解读。用户的图片路径、张数、语言、关注点全程贯穿，不得中途丢失或弱化。

## 触发边界

| 用本技能 | 不用 |
|---|---|
| "帮我分析/解读这张（这些）图片/文档" | 纯文字问题（直接答，不读图） |
| 多页文档照片"合并成一份解读" | 行业深度研究报告（deepinsight-brief） |
| "把图里的表格提出来"（走第1、3步精简路径） | 政企客户谈参（zhengqi-brief） |

## 全流程（顺序执行，结果全部在对话内输出）

### 第1步 读图（读 references/image-reading.md）
用 read 工具逐张读取用户提供的图片路径（read 对图片返回附件，即视觉输入，无需其他 OCR 工具）。路径不存在、不是图片、或为 PDF 等非图片文件时，列出问题文件向用户索要正确图片，不猜测、不跳过。读完后在对话里用一两句话报备：张数、文档类型初判、清晰度、多图关系判定（同一文档多页→合并分析；主题各异或用户要求逐张→分别分析）。未明说且难以判定时问用户一句，不擅自合并。

### 第2步 主分析（读 references/analysis-contract.md）
按契约在对话中直接输出深度解读：文档类型识别 → 核心概要 → 详细分析 → 关键信息 → 价值总结。遵守 deeplens 排版规范（emoji 标题、引用块、分隔线、卡片式关键信息），**主文不放任何 Markdown 表格**（表格由第3步独立承载，正文至多提一句"完整表格见下方表格还原"）。多图合并时按逻辑重组消除冗余，不做逐图拼接。详细分析合计不少于1000字。仅要求表格提取的精简路径跳过本步。

### 第3步 表格还原（读 references/table-extraction.md）
第1、2步中检测到表格或数据图形（饼图/柱状图/折线图等）才执行：紧接主分析之后，在对话中输出 `## 📊 表格还原` 一节，逐一完整还原所有表格为 Markdown 表格（多级表头拆分说明、数字精确到原文位数、合计行单独标注），每个表格后附 AI 总结。跨页被拆分的同一表格合并为一个。图片完全无表格时跳过本步，不输出该节。

### 第4步 追问建议
紧接其后在对话中输出 `## 💭 你可以继续问` 一节，两部分：

**功能型提示**（固定三项，措辞按本文档内容实例化，让用户知道可以这样说）：
- 📊 **表格深挖**：如"把第 2 张表的同比变化算出来并解读一下"
- 🌐 **联网延伸**：如"联网查查文档里提到的 XX 政策最新进展"
- 🔎 **继续深讲**：如"把第 3 节的实验设计再展开讲讲"

**发散性问题**：8—10 个，重点覆盖文档**没有直接涉及但密切相关**的延伸知识，分四类（🔍 深层追问 / 🌐 拓展延伸 / 💡 实践应用 / ⚡ 前沿思考），每类 2—3 个，Markdown 列表呈现。

### 第5步 自核验（读 references/review-checklist.md）
各部分输出前对照清单自检一遍（关键数字落笔前回看原图核对）；对话中已发出的内容发现问题时，在后续回复中更正并说明。不展示检查过程，不循环审稿。

### 第6步 收尾
末尾一句话邀请继续追问。不创建文件、不输出文件路径。

## 交付后（追问对话）

- 基于本次会话已输出的分析内容回答；涉及细节（小字、印章、图表、手写）可重新 read 原图核对后再答；表格对比直接输出 Markdown 表格；超出图片范围的问题如实告知
- **📊 表格深挖**：基于已还原的表格做计算、对比、趋势与异常分析（如同比、占比、均值），必要时重新 read 原图核对；结论注明出自哪张表
- **🌐 联网延伸**：用户要求"查相关资料/延伸阅读"时，先从文档提取 3—5 个搜索方向（关键词 + 为什么值得查），再用 websearch/webfetch 执行；结果标注来源与时间；公开信息不写成图片内容，图片内容不写成公开报道
- **🔎 继续深讲**：对用户指定的部分做约600字级深挖（背景、含义、影响、类比），与已输出内容不重复
- 用户明确要求把结果保存为文件时才落盘（保存到用户指定路径），平时一律只在对话中输出

## 红线（全程有效）

- **不主动创建任何文件**：分析、表格、追问全部在对话中输出，无 run 目录、无中间产物
- 只认图片文件为输入；用户原图只读不改（不裁剪、不转码、不重命名、不移动）
- 图里没有的不编造：模糊、遮挡、手写难辨的内容标注"（不确定：原因）"，不按常见格式补全数字、编号、名称
- 关键数字、日期、金额、单位与图片原文逐字一致
- 主分析与表格分离：主分析零表格，表格只在 `## 📊 表格还原` 节
- 正文不出现流程噪声（无"作为AI"、无自我保证）
