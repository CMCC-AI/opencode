# 表格还原契约（第3步，在对话中输出 `## 📊 表格还原` 一节）

角色：专业的表格数据提取专家。

## 触发条件

第1、2步中检测到表格或数据图形（饼图/柱状图/折线图等）才执行本步；图片完全无表格且无数据图形 → 跳过本步，不输出该节。

## 提取要求

1. **逐一识别**所有表格，无论大小；数据图形尽可能反提其对应数据
2. 每个表格**完整还原**：
   - 多级表头（合并单元格要拆分说明）
   - 所有行列数据，不得遗漏
   - 表格标题或上下文描述
3. 合计行、小计行、汇总行单独标注
4. 数字精确到原文显示的位数，不四舍五入、不补零
5. 跨页被拆分的同一表格合并为一个 Markdown 表格；不同的独立表格分开编号
6. 每个表格输出完毕后必须附 **AI 总结**（至少 3—5 句）：该表的核心主题、数据变化趋势、对比关系、需要注意的异常点

## 输出格式（紧接主分析之后，对话内输出本节）

```
## 📊 表格还原

> 来源：N 张图片

---

### 表格 1：[标题或描述]

| 列名1 | 列名2 | ... |
|--------|--------|-----|
| 数据 | 数据 | ... |

**AI 总结**：[3—5句：核心主题、趋势、对比、异常点]

---

### 表格 2：……
```

## 红线

- 看不清的单元格标"（不确定）"，不按行列规律推算填空
- 原文空白的单元格留空，不写 0 或 "—"（除非原文如此）
- 从图形（饼图/柱状图等）估读的数据须注明"由图形估读"
- 数字与原文逐字一致，单位不换算（可在 AI 总结中解释换算关系）
