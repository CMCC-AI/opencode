# 自核验清单（第5步，各部分输出前自检）

对照下列各项**一次检查**，发现问题在输出前修正；对话中已发出的内容发现问题时，在后续回复中更正并说明。不展示检查过程，不循环审稿：

1. 已读取用户提供的全部图片，无遗漏、无多出
2. 主分析结构与契约骨架一致：文档类型 / 核心概要 / 详细分析 / 关键信息 / 价值总结 五节齐全
3. 主分析正文**零 Markdown 表格**（表格只在 `## 📊 表格还原` 节）
4. 排版合规：每个标题带 emoji、关键数字与结论加粗、大板块间有分隔线、段落不超过 3—4 句
5. 关键数字、日期、金额、单位与原图**逐字一致**（至少抽查 5 处，其中含最关键的 3 处；不确定时重新 read 原图核对）
6. 不确定内容均已标注"（不确定：原因）"，无凭常见格式补全的编号、数字、名称
7. 多图合并模式无逐图拼接痕迹（单一连贯结构）；分别模式每张独立成节且关键信息、价值总结统一收口
8. 追问建议包含三项功能型提示（📊 表格深挖 / 🌐 联网延伸 / 🔎 继续深讲，措辞已按文档实例化）+ 8—10 个发散问题（四类各 2—3 个，聚焦文档未直接涉及的延伸知识而非复述原文）
9. 无占位符残留（如"[待补充]"）、无流程噪声、无"作为AI"、无自我保证
10. 未创建任何文件（除非用户明确要求保存）；语言与用户一致（默认中文）
