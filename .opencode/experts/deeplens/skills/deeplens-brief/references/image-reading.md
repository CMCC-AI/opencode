# 图片登记纪律（第1步）

## 输入认定

- 输入只认图片文件：png / jpg / jpeg / webp / gif / bmp
- 用户给的是 PDF、Word 等 → 明确告知本技能只读图片，请导出为图片后提供，不自行转换
- 用 read 工具逐张读取；读取成功即获得视觉内容，不需要额外 OCR 工具
- 路径不存在、文件损坏 → 列出问题文件请用户修正；不猜路径、不静默跳过

## 读图时掌握的信息（不落盘，对话内一两句报备即可）

- 页序 + 文件名（或路径末段）
- 文档类型初判：报告 / 票据 / 合同 / 论文 / 笔记 / 表格截图 / 海报 / 其他
- 清晰度与完整度观察：是否模糊、裁切、反光、遮挡、手写比例
- 与其他图片的关系：同文档连续页 / 独立主题

## 多图模式判定

| 判定 | 模式 | 处理 |
|---|---|---|
| 版式一致、内容连续（页码、标题、章节延续） | 合并 | 第2步综合分析，跨页表格第3步合并 |
| 主题各异，或用户明说"逐张/分别分析" | 分别 | 第2步每张独立成节，不强行融合 |

未明说且难以判定时问用户一句，不擅自合并。

## 读图纪律

- 先整体后局部：先把握整页结构与类型，再核对数字、日期、签名、印章、小字
- 关键数字落笔前回看原图（可重新 read 该图）核对
- 不确定内容（模糊/遮挡/手写难辨）逐项标注"（不确定：原因）"，禁止按常见格式补全
- 原图只读：不裁剪、不压缩、不重命名、不移动
