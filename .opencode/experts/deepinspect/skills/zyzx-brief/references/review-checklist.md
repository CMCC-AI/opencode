# 自核验清单（第7步，一次执行，不循环）

对 50-report.md 逐项检查，发现问题就地修复一次后结束，不发起多轮审稿。

## 数字核验

- [ ] 每个关键数字与 20-issues-ledger.md 事实链内嵌原值一致：值、单位、小数位、正负号、期间、主体
- [ ] 无心算编造的差额/增幅/占比；有计算的标明了依据
- [ ] 不同口径数字没有混同；同一数值没有跨材料误相加；不同单位/期间金额没有直接合计
- [ ] 状态词与材料一致（已整改/整改中/未说明不升级降级）

## 归并核验（执行过第4步时）

- [ ] 每个共性组满足独立证据要求（跨单位≥2独立单位 / 单位内≥2独立条线）
- [ ] 正文"普遍存在""多发频发"类断言均有共性组支撑；未归并事项无此类表述
- [ ] 问题计数按去重后原子事项；共性/个性/典型未相加；典型标签未升级定性
- [ ] 重复判定有理由；冲突版本并列保留未被裁决

## 定性与分层核验

- [ ] 纪律和政治定性无升级（材料写"工作不规范"不写成"违反纪律"）
- [ ] 已发生事实、材料建议、本报告分析建议三层无混写；整改建议与已实施措施分开
- [ ] 材料未说明整改状态未被解读为未整改
- [ ] 材料不能证明的因果均标注"待核实/需进一步核验"

## 引用与结构核验

- [ ] 正文每个 [N] 与文末参考文献一一对应、无缺号重号；每条参考文献在正文至少被引用一次
- [ ] 参考文献只含真实来源（材料文件名），不含元说明文件
- [ ] 章节结构与 10-requirements 用户章节逐字一致（章名未改写）；用户必答项全部有章节承载
- [ ] 篇幅达到要求或缺口已如实标注；用户要求摘要时摘要合规（单段≤500字）

## 洁净核验

- [ ] 正文无 SRC-*/ISSUE-*/G1 等机器编号、无"图表建议"以外的流程噪声、无内部路径
- [ ] 无模型自我保证、置信度标签、待确认台账
- [ ] 末尾声明句在位且与 00-input.json 的 disclaimer_text 一致（供渲染校验）

## 渲染预检（第8步前）

- [ ] 图表候选数据全部：真实（台账事实链有原值）、可比（同口径）、有独立分析价值；不满足的不进 61
- [ ] `61-quick-charts.json` 契约键仅 `id`/`title`/`option`/`table`，无 `note` 等非契约键；`title` 与60首行H1逐字一致
- [ ] 全文累计汉字数（`[\u4e00-\u9fa5]` 口径、不含参考文献）≥ 台账最低字数
- [ ] "图表建议"标注与正文数据表一致；≤6 幅
- [ ] 50-report.md 与 60-quick-report.md 正文一致（60 只多图表占位）
