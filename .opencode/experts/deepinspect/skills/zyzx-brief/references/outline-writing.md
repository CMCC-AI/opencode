# 章节蓝图与证据规划（第5步）

写 `40-outline.md`。围绕逐章用户指令分配篇幅、事实、研判与图表素材。**不提前写长草稿**。

## 章节来源（优先级从高到低）

1. 10-requirements 章节表（用户原话/要求文件）：**章名逐字保留、顺序不变**，不添加通用"引言/总结"覆盖用户模板
2. 用户未定义时按材料类型拟定，并在蓝图标注"模型拟定结构"
- 章名不改写；模型拟定的备用结构可由蓝图纠正，用户结构不可

## 篇幅预算

- 各章 `target_words` 之和 ≥ 台账目标字数；不足时**按原比例上调，不降低用户目标、不删事实**
- 长章（>6000字）拆**自然子节**（每单元约 3000–5000 字，按内容逻辑拆，不按字节截断）；共享全章主线、术语与用户原话要求，各子节不重复写引言总结
- 章节较短时可整章一个写作单元

## 蓝图格式

```
## 一、<章名逐字>
- id：section-01
- 用户写法：<本章用户原话与具体分析路径>
- 目标字数：5000
- 证据归属：ISSUE-001, ISSUE-004；或类型选择器：common（共性组成员）/ individual（未归并独立问题）/ measure / suggestion / context
- 图表规划：
  - <数据关系>｜来源 SRC-00X｜口径 <同口径条件>｜形式 柱状/表格/时间线｜位置 <正文何处>
- 写作单元：
  - （一）<自然子节标题>｜4000字｜证据 ISSUE-00X,…｜写法要求
```

- 证据可跨章复用（如问题章用 issue 事实、整改建议章也用同一事实作依据），在两章都登记
- 类型选择器在归并完成后解析为具体 ISSUE 编号；未映射证据保留并在蓝图披露归属缺口

## 图表规划纪律

- 只规划**报告中真实、可比、有独立分析价值**的数据关系；同口径才可比，原值在台账
- 没有可比数据时规划流程、时间线或"问题—整改"对照关系；流程与时间线节点必须来自材料
- **禁止规划编造的比例、因果链或风险评分**
- 图表数量不设机械配额（渲染上限 6 幅，超出时优先保留最有分析价值的）

## 失败兜底

蓝图阶段无法确定结构时：优先使用台账中用户明确章题；无真实章题才保守拟定（总体情况→主要问题→整改建议三章）并在蓝图标注"应急结构需人工核对"。
