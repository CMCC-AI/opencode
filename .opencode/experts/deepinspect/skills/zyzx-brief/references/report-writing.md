# 巡察公文写作与统计纪律（第6步）

按 40-outline 分批写作 `50-report.md`：每批 ≤6000 字，**每写完一批立即落盘再写下一批**。写作依据 = 蓝图 + 问题台账对应记录 + 要求台账，不在上下文重囤全部原文。

## 公文表达（用户未另定写法时）

- **完整公文段落为主**，不把分析压成要点、卡片或提纲
- 论证链：明确事实 → 具体表现 → 证据支持的机制与成因 → 影响或风险 → 有针对性的建议
- 共性问题按**【共性表现】【具体事实】【综合研判】**展开，每项写完整段落并保留逐单位表现，不吞掉个性差异
- 个性问题按**【涉及单位】【具体事实】【风险表现】**展开
- 用户明确四级问题标题或标签体系时严格服从
- 材料不能证明的因果写成"待核实研判"，不用经验代替事实；不用政策套话凑字
- 摘要（用户要求时）：单一完整段落、通常不超过 500 字，不堆引用和图表
- 导语只有确有需要时采用"情境—问题—分析"组织，不反复写开头结尾

## 篇幅与批次

- 按各写作单元 target_words 足量撰写，不以"轻量"或时间为由缩篇
- 每批写完落盘；下批开写前不回读全篇，只对照蓝图与台账
- **字数前置自检（每批必做）**：每批落盘后立即以 `[\u4e00-\u9fa5]` 统计 `50-report.md` 全文累计汉字数（与渲染引擎 quick_report_chinese_chars 同口径、不含参考文献）。低于台账最低字数时当补足：扩补段落按"缺口×1.15"字数**一次规划、一批写入**，禁止逐句试探多轮小改，禁止留到渲染后返工
- **批次追加写入**：新批次内容从文件末尾追加（文末短锚点或追加写），不以正文长段作为编辑锚点，避免重复生成已写内容
- 材料薄弱时：充分阐述已有事实、证据范围、差异和可操作核实方向，**不编造案例、责任人、期限、状态**；篇幅实在不足时如实标注缺口

## 引用规范

- 具体事实**就近标注 [N]**，N 对应台账引用编号表；同一来源复用同一编号
- 引文使用台账登记的最小充分原文；有省略的引用不得冒充连续原文
- **不输出 SRC-\*、ISSUE-\*、G1 等内部编号、HTML 注释或本地路径**；参考文献由 SKILL.md 渲染节统一成文
- 来源中的业务缩写正常保留

## 数据表与图表素材（正文内的 Markdown 表）

- 每张表：表题、原值、单位、期间、对象范围、[N] 来源列齐全
- 表后用正式中文说明该比较**支持什么判断**，不只丢一张表
- 口径不一致或冲突的数据**分列**，不作同图比较
- 图表位置用可见中文"图表建议：…"标注（一行独立成段），供第8步转 61 图表

## 统计纪律（全程红线）

- 不重复计数；共性/个性/典型标签不相加
- 不同单位、期间或口径的金额不直接合计；不虚构比例
- 材料未说明整改状态不解释为未整改
- 未定位的数字不写入确定性结论；未核验数字只作"材料载明"转述

## 整改综合表

- 覆盖用户要求的**全部**对应范围（全部单位/全部小节），不能只取代表案例
- 建议与材料已实施措施严格区分

## 自检（每批写完一次，不循环）

用户本章要求是否完整落实、数字单位是否与台账一致、来源是否就近、冲突是否保留、正文是否足量、内部标记是否消除。
