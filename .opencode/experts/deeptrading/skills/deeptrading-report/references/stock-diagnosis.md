# 股票诊断·三面框架（stock-diagnosis）

> **何时加载**：诊断（diagnosis："诊断 XX / 给 XX 做个体检 / XX 怎么样（要求系统性评估）/ 从资金面基本面技术面分析 XX"）；异动分析的三面框架变体（"从三面诊断 XX 的异动"）也加载本篇。
>
> **契约关系**：支撑 60 的"三面体检 → 消息面核对 → 共振/背离矩阵 → 风险提示"章节；三面状态表与资金流时序是图表的天然素材。

## 核心目标

**标准化体检**：资金面 / 基本面 / 技术面各自独立取证、独立判断，再交叉成共振/背离矩阵，输出"当前状态 + 最大风险点"，不给买卖指令。可复现、可跨标的对照。

## 分析步骤

1. **确认诊断范围**：标的、时间窗（默认近 60 交易日）、用户侧重（短线交易视角 / 中长期配置视角——影响三面权重，见避坑）。
2. **资金面（先看钱）**：
   - `akshare_get_fund_flow`（近 20-60 日）：主力净流入的**累计方向与连续性**（连续流入/流出/进出交替）、**超大单 vs 大单结构**（超大单占比高偏机构行为，大单为主偏游资/短线）、净占比与涨跌是否配合（资金进 + 价滞涨 = 分歧）。
   - 输出：资金状态一句话定性（流入 / 流出 / 博弈）+ 强度分级（累计净额 vs 近期日均成交额）。
3. **基本面（再看经营）**：
   - `akshare_get_fundamentals`（概况 + 主营构成 + 财务摘要）；需要纵深时补三表。
   - 三个维度：**成长**（营收/归母净利润增速）、**盈利质量**（毛利率、ROE、经营现金流与利润匹配度）、**结构与杠杆**（主营集中度、资产负债率）。
   - 预期差视角：当前经营趋势 vs 近期股价表现的错位（基本面向好但资金流出 = 市场暂不认；基本面走弱但资金抢筹 = 交易题材）。
4. **技术面（后看价）**：
   - `akshare_get_stock_data`：趋势方向、量能配合、近期高低点。
   - `akshare_get_indicators`：`close_50_sma`/`close_200_sma` 定中期趋势与牛熊位、`macd`/`macdh` 动量、`rsi` 超买超卖、`boll_ub`/`boll_lb` 压力支撑带、`atr` 波动容差。
   - 关键位表述：**支撑 = max(boll_lb, 近期低点)，压力 = min(boll_ub, 近期高点)，均 ± 0.5×ATR 容差**，不报精确点位。
5. **消息面核对（防漏项）**：`akshare_get_news` + `akshare_get_company_announcements` 过一遍近 2 周——三面结论与消息面冲突时（如资金面大进但无任何利好），优先补查再下结论。
6. **共振/背离矩阵（综合）**：

   | 组合 | 解读 |
   |---|---|
   | 资金进 + 价强势 + 基本面稳 | 顺趋势，关注持续性 |
   | 资金进 + 价滞涨 | 分歧加剧，警惕诱多 |
   | 资金出 + 价走弱 + 基本面弱 | 趋势向下的相互确认 |
   | 资金出 + 价强 | 获利兑现，观察承接 |
   | 三面指向不一 | 状态不明，如实写"无共振"，不硬给结论 |

7. **风险提示（必写章节）**：三面各自的最大风险点各 1 条 + 综合判断的失效条件（如"主力净流入连续 5 日转负则资金面结论失效"）。

## 异动分析变体（三面 × 归因锚点）

以异动日为锚：资金面看异动日单日 + 前 5 日主力净流入变化（放量上涨是否有真实资金承接）；基本面看是否有新披露（公告/财报/业绩预告）；技术面看异动发生的位置（低位 / 高位 / 突破位 / 破位——位置决定同一放量是吸筹还是出货）。先定位**主驱动面**，再用三面交叉验证，最后按 `abnormal-detection.md` 的驱动四类归因。

## 取数（本包数据源）

- 资金面：`akshare_get_fund_flow`（个股）；行业视角加 `akshare_get_sector_fund_flow`
- 基本面：`akshare_get_fundamentals` + 三表（按需）
- 技术面：`akshare_get_stock_data` + `akshare_get_indicators`
- 消息面：`akshare_get_news` / `akshare_get_company_announcements`

## 避坑

- **资金流是结果不是原因**——主力净流入与涨跌是同一笔成交的两面，不得写成因果
- 单日资金数据噪音大，判断看 5-20 日累计与连续性
- 三面权重随投资周期变：短线资金面 > 技术面，长线基本面 > 技术面——报告开头声明口径
- 诊断 ≠ 评级：输出状态与风险提示，**不给买卖指令**（红线）
- 北交所标的无资金流数据，如实标注"资金面缺口"，两框架下结论
- 关键位一律带 ATR 容差，避免伪精确点位
