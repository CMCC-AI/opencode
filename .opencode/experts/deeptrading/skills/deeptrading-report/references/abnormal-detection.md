# 放量异动与跳空归因（abnormal-detection）

> **何时加载**：归因（attribution）中量价异动子场景："X 今天为什么大涨 / 放量是什么意思 / 跳空怎么解读 / 盘中突然异动 / 主力出货还是吃货"。AI 复盘的日内层方法论。
>
> **契约关系**：支撑 60 的"事实校准 / 驱动拆解"章节；量价数据是图表的天然素材。

## 核心目标

**快速识别放量 / 跳空驱动来源**，区分信息含量与情绪扰动，判断可信度与后续跟踪价值。

## 分析步骤

1. **确认偏离常态**：成交额 / 成交量是否显著抬升 vs 近阶段常态水平（用 `akshare_get_stock_data` 取近 60-120 日对比当日/当周）、换手率同步明显变化、放量是持续型还是脉冲型、主要集中在哪个时段（开盘 / 尾盘 / 中段——**注意：本包无分钟线数据，时段分布靠 360 智搜的新闻报道还原，标注非一手**）。
2. **驱动排查四类**：
   - **事件驱动**：公告（`akshare_get_company_announcements`）/ 新闻（`akshare_get_news`）/ 政策（`akshare_get_market_news`）
   - **板块驱动**：同行集体异动（对比板块内其他标的日线）/ 题材发酵 / 龙头带动
   - **技术驱动**：关键位突破 / 跌破 / 止损踩踏（`akshare_get_indicators` 的均线/布林带）
   - **资金驱动**：情绪抢筹 / 游资接力 / 博弈换手（`akshare_get_fund_flow` 看异动日单日及前 5 日主力净流入承接；龙虎榜数据本包暂缺，靠新闻检索，注明缺口）
3. **放量质量判断**：
   - 价格是否顺放量方向推进（放量 + 大涨 vs 放量 + 滞涨）
   - "只放量不走价"通常是分歧信号
   - 放量后是否带来结构重估还是一天脉冲
   - 当前市场是否支持延续
4. **位置决定含义**：
   - 低位放量：吸筹 / 启动信号
   - 高位放量：可能出货
   - 突破放量：有效突破信号
   - 冲高回落放量：诱多 / 兑现
   - 下跌放量：恐慌 / 趋势加速
5. **跳空归因**：
   - 事件驱动型（扎实催化）：跳空可持续
   - 情绪强化型（市场过度反应）：跳空易回补
   - 补涨补跌型（相对强弱调整）：跳空有结构意义
   - 技术位置触发型：止损踩踏 / 多头止盈
6. **后续验证重点**：次日是否承接、关键位置是否站稳、题材热度是否继续支持、成交回落后价格是否维持强势。
7. **三面交叉验证**（用户要求系统性诊断异动时）：资金/基本/技术三面独立取证后交叉，见 `stock-diagnosis.md` 的"异动分析变体"——先定位主驱动面，再看三面是否共振。

## 避坑

- 不能把所有放量都等同于利好——高位放量往往是出货信号
- 成交量极限扩大可能反映流动性枯竭而非资金涌入
- 事件催化常在发布前已被市场提前反应——公告出现时反而是利空兑现
- 跳空缺口易被高估——历史数据显示大部分缺口在数周内被回补
- 盘中瞬时放量可能只是程序交易 / 期权对冲——与基本面无关
- 本包数据盲区（分钟线/龙虎榜）导致的判断缺口要在报告里如实说明，不得脑补
