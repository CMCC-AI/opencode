# 估值与定价（valuation-pricing）

> **何时加载**：估值评判（valuation："贵不贵 / PE 多少 / 是否高估 / 重估空间 / 杀估值风险"），以及归因研究中"估值与预期差"章节。
>
> **契约关系**：支撑 60 的"估值位置 / 预期差"章节；估值快照数字可进 61 的 hero_stats。

## 核心目标

回答三件事：**该用什么估值方法、当前估值反映了市场什么预期、未来重估或杀估值的触发因素**。

## 取数（本包数据源）

- 算历史分位、估值中枢**必须长周期**：`akshare_get_fundamentals` / `akshare_get_income_statement` 默认返回期数有限，取数用 `freq=annual` 拿多年年报；估值序列用 `akshare_get_stock_data` 日线 + 财报 EPS 自行推算 PE 分位时，注明推算口径
- 行业可比估值：360 智搜（"X 行业 可比公司 PE PB 2026"），非一手来源标"需核实原文"
- **3 年数据算不准"历史 70% 分位"这类判断**——周期/分位判断取数拉到 5-10 年

## 分析步骤

1. **判断公司类型**：高成长 / 稳健成长 / 周期 / 价值 / 资源 / 平台型 / 金融——不同类型不能用同一套方法。
2. **选择估值框架并解释为什么**：
   - 高成长：PE / PEG / PS / EV-EBITDA
   - 稳健成长：PE / PEG
   - 周期：PB / 周期中枢 PE / 盈利拐点
   - 价值：PE / PB / 股息率
   - 平台 / 金融：分部估值 / DCF / P/AUM 等
3. **拆解当前估值反映的预期**：高估值隐含未来高增速 / 景气持续 / 市占率提升；低估值隐含周期下行担忧 / 业绩见顶 / 治理折价。**说清"股价里已经包含了什么"**，是高质量估值分析的关键。
4. **估值位置判断**：3-5 年历史分位（30% 以下偏低、30%-70% 中性、70% 以上偏高），同时行业横向对比，结合公司质地与阶段——高估值不一定贵、低估值不一定便宜。
5. **重估 / 杀估值触发因素**：
   - 重估来自：业绩超预期 / 产业趋势强化 / 商业模式改善 / 资金风格切换 / 治理改善
   - 杀估值来自：增速下修 / 景气拐点 / 竞争恶化 / 风险偏好下降 / 政策冲击
6. **DCF 关键参数（如果用）**：WACC 区间通常 8%-12%，永续增长率 2%-3%，做 Bear / Base / Bull 三情景，**不要把单一情景当目标价**。
7. **形成判断**：当前估值是否有性价比、投资重点是赚业绩钱还是赚估值钱、当前更适合乐观 / 审慎 / 等待。

## 避坑

- 不生搬硬套——必须解释为什么这个方法最适合这家公司
- 不能只给 PE 数字就下结论，必须拆解估值背后的预期
- 高估值不是"一定要卖"信号，看增速与质量是否匹配
- 跨公司比 PE 前先核对财年口径（见 peer-comparison.md 的 FY 对齐）
- 不给具体目标价点位预测，可给估值区间和情景
