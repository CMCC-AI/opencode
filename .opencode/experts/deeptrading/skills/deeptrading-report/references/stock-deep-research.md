# 个股深度研究（stock-deep-research）

> **何时加载**：归因（attribution）、前瞻（outlook）、单标的深度问题（"X 值不值得研究""X 的投资逻辑"）。
>
> **契约关系**：本篇方法论支撑 60 报告的"驱动拆解 / 预期差 / 结论"等章节的**分析过程**；章节结构仍以《问题类型路由表》骨架为准。

## 核心目标

不是资料堆砌，而是回答两件事：**市场为什么会买这只股票，未来还会不会继续买**。

## 分析步骤

1. **拆解公司与业务结构**：哪块业务最关键、哪块决定估值、是否有真壁垒。区分主业务、增长业务、衰退/边缘业务。
2. **行业格局与公司位置**：行业阶段（导入 / 成长 / 成熟 / 下行）、行业空间、竞争强度、公司位置（龙头 / 细分龙头 / 追赶者 / 边缘）。
3. **核心投资逻辑（2-4 条）**：每条必须包含——逻辑本身、为什么成立、对业绩或估值的影响路径、是否已被充分定价。**不接受**"受益于行业发展"这种泛逻辑。
4. **未来 1-3 年增长驱动**：来自产品放量、价格上行，市场份额，新业务，成本改善中哪一个；明确**最关键的业绩变量**。
5. **市场共识与预期差**（高质量投研的关键交付）：
   - 市场已普遍接受什么
   - 真正可能形成超额收益的预期差在哪，按四个角度排查：**被低估的盈利弹性 / 被高估的短期风险 / 被忽视的新业务 / 周期判断滞后**
6. **估值方法选择与位置**：为什么选这个方法（见 valuation-pricing.md）、当前处于历史 3 年分位什么位置、行业横向对比如何。
7. **真正可能伤害股价的因素**：短期与中期风险分开（需求 / 价格 / 客户集中 / 产能 / 政策 / 竞争），不要泛泛提示。
8. **一句话本质**："买这家公司本质上是在买 ____"（如"买的是 AI 算力资本开支周期的量价齐升"）——逼自己把投资逻辑收敛成一句可证伪的话。放进 60 的核心观点块。

## 取数（本包数据源）

- 业务与主营构成：`akshare_get_fundamentals`（概况 + 主营构成 + 最新财务摘要，自带披露时点）
- 长周期财务（看周期与中枢）：`akshare_get_income_statement / get_balance_sheet / get_cashflow` 带 `freq=annual` 取多期
- 行情与估值背景：`akshare_get_stock_data`（日线）、`akshare_get_indicators`
- 行业格局与新闻背景：360 智搜（"X 行业 竞争格局 2026"）；财报原文 `akshare_get_company_announcements`
- **AkShare 不可用时**：全部降级 360 智搜 + webfetch，正文注明口径风险

## → 61 图表挂钩

本篇方法自然产出的结构化数据与适配图型：

| 方法论产物 | 图型 |
|---|---|
| 主营构成拆分（收入占比） | 饼图或横向条形 |
| 多期营收/净利/ROE 序列 | 柱线双轴（量级差大时） |
| 近 12 月价格走势（配合驱动拆解） | 折线 + markPoint 标注关键事件日 |
| 估值历史序列（PE/PB） | 双轴折线，markPoint 标注分位极值 |

## 避坑

- 不写公司介绍式资料堆砌
- 每条投资逻辑要具体到影响路径，不接受"受益于景气"这种泛话
- 预期差是核心交付，不能敷衍
- 数据用来支持判断，不要堆数据没结论
- 60 报告中该标的的关键数字必须带来源+时点标注
