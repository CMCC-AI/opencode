# 通用品类模板（_template）

> 当 `category-profiles/` 下找不到匹配品类时，团长与各专家一律走本模板。**绝不能因为缺品类模板而失败。**

## 真实购买目标（先想清楚用户到底在解决什么）

用户买东西通常不是为了参数，而是为了解决一个生活问题。常见范式：

- **省心**：不要折腾、坏了有人管、操作简单。
- **体面**：送人 / 社交场合，审美、品牌感、包装重要。
- **性价比 / 临时用**：便宜够用、坏了不心疼。
- **专业 / 进阶**：为某项能力买单，愿意接受取舍。
- **健康 / 安全**：成分、刺激性、适用人群优先。

需求分析专家（need-analyst）应据此推断 `implicitConcerns`。

## 通用关注维度（按当前用户重新排序）

- 价格 / 预算匹配
- 可靠性 / 耐用度
- 易用性 / 学习成本
- 售后 / 保修 / 网点覆盖
- 外观 / 审美 / 颜值
- 品牌 / 口碑 / 信任度
- 便携 / 体积 / 空间
- 环保 / 成分 / 安全性

**排序规则：** 把 `recipient`（给谁用）+ `scenario`（什么场景）作为加权依据。例如：

- 给老人 / 父母 → 易用性、售后、可靠性 提到前面。
- 送礼 → 审美、品牌感、包装 提到前面。
- 出租屋临时用 → 价格、便携 提到前面。

## 常见避坑点

- 不要被单一高参数吸引而忽略短板（如手机跑分高但续航差）。
- 警惕营销话术（“性价比之王”“旗舰杀手”多半是软文）。
- 同款不同平台价差可能来自版本 / 赠品 / 真假风险。
- 注意“适用人群”错配（如给油皮推荐滋润型护肤品）。

## 扩展维度（由专家在搜索中动态补充）

本模板不预置品类专属参数表。产品分析专家在搜索过程中，根据品类常识动态补入关键参数维度，并写入候选的 `categoryNotes`。

---

> 新增品类时复制本文件改名为 `<key>.md`，按下方结构补内容即可：
> - 真实购买目标
> - 品类关注维度（带默认排序）
> - 常见避坑点
> - 关键参数怎么看（供产品分析专家）
