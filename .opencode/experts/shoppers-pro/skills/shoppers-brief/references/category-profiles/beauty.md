# 美妆护肤（beauty）

## 真实购买目标（先想清楚用户到底在解决什么）

买美妆护肤的人其实在解决：

- **肤质适配**：油皮怕闷痘、干皮怕拔干、敏感肌怕刺激。
- **场景效果**：通勤要不泛白、户外要高防护、约会要持妆。
- **成分安全**：孕期 / 敏感肌 / 儿童对成分有硬约束。
- **性价比 / 容量**：日耗品，单价 ÷ 容量 ÷ 用量才是真成本。
- **妆效偏好**：哑光 / 水光 / 自然。

## 品类关注维度（默认顺序，按当前用户重排）

1. 肤质适配（油 / 干 / 敏 / 中）—— 最关键，错配直接淘汰
2. 刺激性 / 成分安全（酒精 / 香精 / 防腐剂 / 致痘等级）
3. 核心功效（防护力 / 保湿力 / 控油力 / 遮瑕力）
4. 妆效 / 肤感（成膜速度 / 泛白 / 拔干 / 假白）
5. 容量 / 单位价格（每毫升成本）
6. 便携 / 补涂便利
7. 品牌口碑 / 真假风险
8. 价格 / 预算匹配

**油皮通勤重排为：** 肤质适配 > 成膜不泛白 > 控油持妆 > 刺激性 > 容量单价 > 价格。

## 关键参数怎么看（供产品分析专家）

- **防晒**：SPF（UVB）+ PA（UVA）；通勤 SPF30 PA+++ 够，户外 SPF50+ PA++++。
- **成膜**：成膜快 = 不黏腻不泛白，通勤补妆友好。
- **质地**：啫喱 / 乳液 / 摇摇乐；摇摇乐控油强但可能拔干。
- **成分**：物理（氧化锌/二氧化钛，温和但泛白）vs 化学（肤感好但可能刺激）vs 物化结合。
- **容量**：50ml 是常见规格，日耗品注意每次用量（脸约 1g）。

## 常见避坑点

- 只看 SPF 数字忽略 PA（UVA 才是光老化主因）。
- 假白 / 泛白严重，通勤社交尴尬。
- 含酒精给敏感肌用 → 泛红刺痛。
- 摇摇乐不摇匀 → 防护力下降。
- 网红爆款适合特定肤质，不等于适合所有人；警惕软文。
- 美妆真假风险高，非官方渠道谨慎。

## 适合理由示例（针对不同用户的差异）

- 油皮通勤：成膜快不泛白、控油持妆、可叠加妆前、容量够用一个月。
- 敏感肌：物理防晒温和、无酒精香精、不易闷痘。
- 户外：SPF50+ PA++++、防水抗汗、需要补涂。
