# 手机（phone）

## 真实购买目标（先想清楚用户到底在解决什么）

买手机的人很少真在比跑分，更多是在解决：

- **给父母 / 老人**：不要反复学习、出门少充电、坏了有人帮、看得清屏幕。→ 易用性、续航、售后优先于性能。
- **给自己日用**：流畅、拍照好看、信号稳、系统顺手。
- **学生 / 预算紧**：便宜够用两三年，耐摔、存储够。
- **影像 / 极客**：为影像系统或性能上限买单，愿接受取舍。
- **商务**：信号、续航、稳重外观、隐私安全。

## 品类关注维度（默认顺序，按当前用户重排）

1. 性能（CPU / GPU / 存储规格）—— 决定流畅寿命
2. 屏幕（尺寸 / 亮度 / 护眼 / 刷新率）
3. 续航（电池容量 / 快充功率）
4. 影像（主摄 / 长焦 / 防抖 / 夜景）
5. 系统与易用性（广告 / 简易模式 / 字体 / 误触防护）
6. 售后与可靠性（网点密度 / 碎屏险 / 系统更新周期）
7. 价格 / 预算匹配
8. 外观 / 重量 / 材质

**给父母重排为：** 易用性 > 续航 > 售后 > 屏幕 > 影像 > 性能 > 价格 > 外观。

## 关键参数怎么看（供产品分析专家）

- **处理器档位**：旗舰 / 次旗舰 / 中端 / 入门，对应流畅寿命预期（3~4 年 / 2~3 年 / 1~2 年）。
- **内存 / 存储**：建议 12GB+256GB 起步；给长辈也至少 8+256，照片视频占空间快。
- **电池**：5000mAh 是当前甜点；快充 60W+ 能显著缓解续航焦虑。
- **屏幕**：护眼（DC 调光 / 高频 PWM）对长辈和敏感人群重要；亮度决定户外可见。
- **影像**：别只看像素，看传感器和有没有长焦；给长辈“拍得清、对焦快”比“夜景极致”实用。

## 常见避坑点

- 纸面跑分高但散热差 → 游戏掉帧、长期降频。
- 入门机存储小（128GB）→ 半年就塞满，别给爱拍照的长辈买。
- 系统广告 / 预装多 → 给长辈买要选能关广告或广告少的品牌。
- 线上机型与线下机型配置差异大，售后网点密度因品牌差异极大。
- “影像旗舰”若无长焦，望远能力其实一般。

## 适合理由示例（针对不同用户的差异）

- 给父母：大字体简易模式、5000mAh+ 续航、附近有售后网点、存储够装孙辈照片。
- 油皮通勤族（自拍多）：前置人像强、护眼屏、续航撑一天。
- 学生：价格内性能最优、耐摔、存储够。
