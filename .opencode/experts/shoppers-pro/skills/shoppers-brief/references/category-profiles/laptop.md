# 笔记本（laptop）

## 真实购买目标（先想清楚用户到底在解决什么）

- **剪视频 / 创作**：要算力、要屏幕色准、要散热，愿接受重量和价格。
- **办公 / 商务**：轻薄、续航、接口够、稳定。
- **学生**：性价比、够用四年、轻便带去图书馆。
- **游戏**：GPU、散热、刷新率，重量和续航取舍。
- **写代码**：内存大、屏幕好、键盘手感 / 外接友好。

## 品类关注维度（默认顺序，按当前用户重排）

1. CPU（代际 / 核心 / 单核性能）—— 决定生产力上限
2. GPU（核显 / 独显档位）—— 创作和游戏的关键
3. 内存（16GB 起，创作 / 开发建议 32GB+）
4. 屏幕（分辨率 / 色域 / 色准 / 亮度 / 刷新率）
5. 散热（高负载下能否维持性能）
6. 便携性（重量 / 厚度）
7. 续航
8. 接口 / 扩展性
9. 价格 / 预算匹配

**剪视频重排为：** CPU > GPU > 内存 > 屏幕色准 > 散热 > 便携 > 续航 > 价格。
**办公重排为：** 便携 > 续航 > 接口 > 屏幕 > CPU > 价格。

## 关键参数怎么看（供产品分析专家）

- **CPU**：Intel Core Ultra / AMD Ryzen 8000 / Apple M 系列代际决定档位；剪视频看多核 + 编码引擎（ProRes / NVENC / QSV）。
- **GPU**：核显够轻度剪辑 / 网游；独显（RTX 4050/4060/4070）决定达芬奇 / Premiere 流畅度和 3D 渲染。
- **内存**：16GB 是底线，剪 4K 多轨建议 32GB+，且要看是否板载（不可升级）。
- **屏幕**：100% sRGB 是底线；创作要 100% DCI-P3 + 出厂校色（ΔE<2）；亮度 400nit+ 户外可用。
- **散热**：看热管数量和性能释放瓦数（PL1/PL2），轻薄本常降功耗换安静。
- **存储**：512GB 起步，创作建议 1TB+；看是否双 M.2 可扩展。

## 常见避坑点

- “i7”不等于强——代际比 i5/i7 更重要，老代 i7 不如新代 i5。
- 板载内存不可升级，买时就要定够。
- 轻薄本标压但散热压不住 → 持续降频。
- 屏幕只标分辨率不标色域 → 45% NTSC 低色域屏创作不能用。
- 游戏本续航极短、噪音大，办公场景反受罪。

## 适合理由示例（针对不同用户的差异）

- 剪视频：多核强 + 有独显编码 + 32GB + 高色域屏，能流畅剪 4K。
- 学生：性价比 CPU + 16GB + 轻便，够用四年。
- 商务出差：1.3kg 内、续航 10h+、接口全、不用带扩展坞。
