# 礼品（gift）

## 真实购买目标（先想清楚用户到底在解决什么）

买礼品的人核心在解决 **关系与表达**，不是买商品本身：

- **体面**：不能显得廉价、要有品牌感、包装要拿得出手。
- **得体**：符合双方关系（领导 / 客户 / 长辈 / 朋友 / 情人），不过分也不寒酸。
- **安全**：不踩禁忌（谐音 / 文化 / 宗教 / 过于私人）。
- **审美匹配**：对方审美未知时走经典稳妥，不押注个性款。
- **预算即心意**：预算区间要“看起来值”，而不是“实际便宜”。

## 品类关注维度（默认顺序，按当前用户重排）

1. 关系得体度（是否匹配双方身份 / 场合）
2. 品牌感 / 价值感（“看起来值多少”）
3. 包装 / 仪式感
4. 审美稳妥度（经典 > 个性，除非很懂对方）
5. 禁忌 / 文化安全
6. 价格区间匹配（预算要花在“显眼”的地方）
7. 实用性（因人而异，送长辈实用加分，送领导慎选）
8. 可携带 / 邮寄

**送领导重排为：** 品牌感 > 得体度 > 包装 > 审美稳妥 > 禁忌安全 > 价格。
**送长辈重排为：** 实用 > 得体度 > 品牌感 > 包装 > 价格。

## 关键参数怎么看（供产品分析专家）

- **价值感来源**：品牌（百年 / 知名）、材质（真材实料）、工艺（手工 / 限量）、包装（礼盒 / 烫金）。
- **稳妥度**：经典款 > 当季款 > 个性款；中性审美 > 强风格。
- **体积 / 携带**：能否当面递交、是否需要邮寄、是否易碎。
- **可补救性**：选错是否容易退换 / 转送。

## 常见避坑点

- 价格透明且偏低（如明显打折款）→ 显得没诚意。
- 太私人 / 太个性（香水味型、服饰尺码）→ 容易踩雷。
- 谐音 / 文化禁忌（送钟、送鞋、送伞给某些关系）。
- 包装廉价毁掉好东西。
- 送领导太贵 → 像行贿；太便宜 → 像敷衍，区间要拿捏。
- 保质期类（食品 / 鲜花）物流风险高。

## 适合理由示例（针对不同用户的差异）

- 送领导：品牌经典款 + 礼盒包装 + 审美中性稳妥 + 预算花在显眼处。
- 送客户：体面可邮寄 + 不踩禁忌 + 留有余地可转赠。
- 送长辈：实用 + 健康 + 包装得体，避免过于花哨。
- 送情人：个性化可押注（懂对方时）、仪式感强。
