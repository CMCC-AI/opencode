# 家电（home-appliance）

> 覆盖：洗烘套装、冰箱、空调、电视、扫地机器人、厨房小家电等。

## 真实购买目标（先想清楚用户到底在解决什么）

- **省心耐用**：家电坏了麻烦，售后和可靠性 > 极限参数。
- **操作简单**：给老人买，复杂的 APP / 触屏反而是负担。
- **空间适配**：尺寸 / 嵌入 / 进出门 / 老房子安装条件。
- **能耗 / 噪音**：长期使用成本和居住舒适度。
- **新房 / 装修**：一次性配齐，关注套系美观和安装协调。

## 品类关注维度（默认顺序，按当前用户重排）

1. 可靠性 / 品牌售后（网点 / 保修年限 / 上门）
2. 核心性能（洗净比 / 制冷量 / 容量 / 吸力 等）
3. 尺寸 / 安装条件（嵌入尺寸 / 排水 / 电压 / 承重墙）
4. 能效等级（一级 / 二级，长期电费）
5. 噪音（dB，影响睡眠 / 客厅）
6. 易用性（物理按键 / 老人模式 / APP 复杂度）
7. 价格 / 预算匹配
8. 外观 / 套系协调

**给父母重排为：** 易用性 > 售后 > 可靠性 > 噪音 > 核心性能 > 价格。

## 关键参数怎么看（供产品分析专家）

- **洗烘套装**：洗净比（>1.03 合格，>1.08 优秀）、烘干容量与冷凝方式（热泵 > 冷凝）、电机（直驱 BLDC）、是否支持洗烘一体（一体机烘干弱）。
- **冰箱**：能效、变频压缩机、风冷无霜、容量与冷冻力、嵌入散热方式。
- **空调**：匹数对应面积（1匹≈12㎡）、能效 APF、新风 / 自清洁、噪音。
- **扫地机**：导航（LDS / 视觉）、避锐、自集尘 / 拖地、基站功能。
- **安装类（空调 / 洗衣机 / 大电视）**：必须确认上门安装条件与收费。

## 常见避坑点

- 参数漂亮但售后网点少 → 坏了等很久。
- 智能家电 APP 复杂 / 需要注册 → 给老人买反而不会用。
- 洗烘一体机烘干效果远不如独立热泵烘干机。
- 嵌入家电尺寸差 1cm 装不进去，先量再买。
- 大家电线上下单要确认楼层 / 进户门 / 安装收费。

## 适合理由示例（针对不同用户的差异）

- 给父母：物理按键多、老人模式、售后网点密、噪音低不影响睡眠。
- 出租屋：便宜、够用、坏了不心疼、能自己搬。
- 新房装修：套系美观、嵌入尺寸匹配、能效一级省电。
