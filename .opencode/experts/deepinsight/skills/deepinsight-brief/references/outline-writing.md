# 大纲设计与分批写作

## 跨源分析（大纲前置，写入 40-outline.md 头部）

- **已回答**：哪些P0/P1有充分证据（列证据卡片号）
- **冲突**：证据间分歧点及并列口径
- **缺口**：P0中证据不足的问题——如实带入大纲作"边界与局限"或在章节内降级表达，不硬下结论
- 报告类型判定：行业综述 / 对比分析 / 政策解读 / 趋势研判 / 事件归因（决定章节骨架）

## 章节蓝图格式

```
# 章节蓝图
类型：<报告类型>
## 章节
1. <章名>（约N字）
   - 要点：<2—4条>
   - 承载：<Q1、Q3>（P0映射）
   - 用证：<E01、E05>
   - 表格/图表候选：<每个数据密集章节至少规划1个候选，注明证据号与**图表类型**（时序→折线/面积；构成→堆叠/饼；对比→分组柱/横向条形；多维→雷达；性价比→散点；双指标→双Y轴）；全篇通常4—6幅且类型尽量不重复
...
- 字数合计：<必须等于目标字数>
```

硬规则：
- **每个P0映射到至少一个章节**；对照10-requirements再查一遍必答问题全覆盖
- 章节字数之和=目标字数；长报告单章不超过总量1/3
- 摘要/引言/结语类短章合计不超过总量20%，可合并成一章
- 证据不足的确定性结论不进大纲；缺口按"边界与局限"或降级表述规划

## 分批写作纪律

- 目标≤6000字：单批成文
- 更长：按自然章节分批，每批≤6000字；相邻短章合并成批；超长章只沿子章节切分，父章标题只在首批出现
- **每批写完立即追加落盘** 50-report.md 再写下一批；写作依据=40-outline对应章+30-evidence对应卡片，不重囤全部原始搜索
- 各批共享：同一引用编号表、统一术语（首次出现给全称）、40-outline全貌；不读取、不引用其他批次正文
- 批次截断只局部续写一次，失败保留已有内容如实标缺口

## 文体

- 自然段为主，分析报告文风；表格用于真实多维对比，列表用于真正的并列项
- 关键数字后给解读（趋势/结构/含义），不裸贴数
- 对比分析保持维度对齐（同一维度比到底，不半途换轴）
- 预测与研判标明依据和置信边界（"基于X趋势，预计…"），不写确定性预言
- 正文关键事实与数据后标[N]（编号表已固定）
- 文末参考文献：每条独立有序列表项 `N. 来源名（说明，时间）`；正文用[N]、列表用`N. `，不混用；条目单换行分隔即可正确渲染，禁止写成裸`[N]`连排
