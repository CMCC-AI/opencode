# 研究规划

## 研究问题分级（写入 20-plan.md）

```
# 研究计划
## P0（必答——用户必答问题 + 不回答报告即不成立的核心问题）
- Q1 <问题> | 证据路径：<材料字段/公开数据/权威源> | 查询方向：<2—4个关键词组合>
## P1（重要——显著提升报告价值）
- ...
## P2（可选——锦上添花，时间允许才做）
- ...
## 路由
- <internal | hybrid | external>：<判定理由>
```

分级纪律：
- 用户台账中的每条必答问题必须是某个P0的原文或子问题
- P0数量通常3—6个；超过8个说明主题过宽，收敛或与篇幅匹配说明
- 每个P0必须有明确证据路径（在哪类来源里能回答），"网上搜搜"不是证据路径

## 路由判定

| 条件 | 路由 | 行为 |
|---|---|---|
| 有上传材料，无公开需求 | internal | 材料深读为主，不搜或仅1—2条补充 |
| 有材料 + 需要行业/竞争/政策背景 | hybrid | 材料深读 + 公开研究补外部维度 |
| 无材料 | external | 纯公开研究 |

路由是内部决策，不展示给用户确认，直接推进。

## 查询设计（公开部分）

- 首轮：每个P0/P1问题1—2条查询，覆盖全部维度后一轮发出；查询含时间锚定词（年份/近三年）
- 查询语言与目标市场匹配（中国主题中英混合查）
- 同一问题不换关键词重复发；规划阶段就设计互补查询，不留到执行时即兴
- 逐条记录执行状态到20-plan.md（已执行/失败/跳过），失败的查询不自动重发
