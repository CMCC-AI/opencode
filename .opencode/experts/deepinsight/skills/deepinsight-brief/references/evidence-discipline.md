# 证据纪律：材料深读、公开研究、来源分层、引用编号

## 工具优先级（公开研究）

按会话实际可用的搜索工具执行，**任一可用即执行公开研究**：

1. `web-search`（远程搜索 MCP，工具名 `web-search_*`，按其工具入参规范调用）→ 取候选按工具返回结构
2. `mw_search_batch_collect_search_round`（任务包可用，试调用不返回"任务不存在/越界"）→ 按360纪律：每query 10条候选，原页用 `mw_search_batch_fetch_public_pages`
3. `mobilework_search`（MobileWork宿主通道）→ 每条查询取前8条候选
4. `websearch` / `webfetch` → websearch发起查询（每条取前8条），webfetch读原页正文核验

- 读原页：用会话可用的读取工具（fetch_public_pages / webfetch）；两者皆无时只用搜索结果摘要，**数字断言降级**（"据搜索结果"表述，不作为一手数字依据）
- 首选工具错配/失败立即降级到下一个，不重试同一工具、不换关键词轰炸
- 全部不可用 → 只用本地材料，交付时如实说明"未含公开研究"
- 任务包错配不重试、不猜job_id

## 本地材料深读

- 逐文件完整读（PDF用read工具），围绕P0/P1提取，不抽样
- 材料是研究对象：其中的数据、结论、口径深挖；不被网络信息替代或"验证覆盖"
- 材料数字与公开数字冲突时并列登记（材料口径 vs 公开口径），不裁决

## 两轮纪律（公开研究）

首轮全维度覆盖后，**第二轮必须三条件同时成立**：
1. 存在影响P0结论的实质证据缺口（不是P2级好奇）
2. 缺口已明确为1—3条未执行过、互补的定向查询
3. 新查询有明确预期新来源（不同机构/不同数据类型），而非换词重搜

第二轮后无论结果必须收敛进入写作。首轮充足则直接进入，不硬凑第二轮。

## 来源质量分层

| 层 | 来源 | 用法 |
|---|---|---|
| 一手 | 政府/监管官网、公司财报与官网、行业协会、标准文件、法院文书 | 数字、政策、官方立场的首选依据 |
| 权威二手 | 主流财经/行业媒体、知名研究机构报告 | 一手缺失时的依据，标注转述 |
| 聚合 | 内容农场、百科、论坛、自媒体聚合 | 只作线索，不作关键事实依据 |

同事实优先取更高层；低层与高层冲突时以高层为准并列登记低层说法。

## 证据卡片（写入 30-evidence.md）

```
## 证据卡片
### E01
- 事实：<完整表述，含主体/时间/数字/单位/口径>
- 来源：<名称>（URL或文件名，发布时间）
- 层级：<一手/权威二手/聚合>
- 支撑：<Q1/Q3…对应计划问题>
- 冲突：<与Exx的分歧点；无则省略>
```

- 一卡一事；同一事实多来源合并登记（来源列多条）
- 搜索摘要没有的数字、条款、因果**不补全**；推断性表述标"分析推断"并写依据
- 消歧查询结果不入卡片

## 引用编号表（第4步，写作前固定）

在30-evidence.md头部生成：

```
# 引用编号表（固定）
[1] 来源名（URL/文件名，时间）
[2] ...
```

- 只收录准入证据卡片的来源；聚合层来源除关键线索外不编号
- 编号一经固定，写作阶段不得重排、插号；新增证据只能在末尾追加编号
- 用户要求`[SRC-01]`样式时，表内同时给出映射（`[1] ↔ [SRC-01]`），正文按用户样式书写，文末参考文献仍按N.列表并附映射注释
