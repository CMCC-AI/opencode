# 首页媒体加载优化

## 源码与发布产物

- 源工程：与 `opencode` 同级的 `product-statspanel`，是独立 Git 仓库。
- 发布产物：`packages/app-cmcc/public/landing`。不要直接修改其中的压缩 JS/CSS。
- 本次不修改 Nginx、后端、业务页面或业务缓存，不自动部署。

## 加载顺序

1. HTML 中直接声明首屏视频，并预加载约 32 KB 的 WebP 封面。封面提取自当前视频第一个画面。
2. Vue 挂载后复用同一个视频元素，不通过额外的 fetch/Blob 或第二个播放器重复下载。
3. 非首屏图片和页尾背景在接近视口 200px 时加载；研究步骤切换仍更新对应动图。
4. 视频实际播放后 3 秒再预取 `/app`；不再首屏 prerender 主应用。视频失败时不预取，不阻止用户点击进入。
5. 图片宽高取自当前素材的真实尺寸，保留加载前的布局空间。更换素材时同步更新宽高；更换视频时重新提取封面。

## 构建同步（PowerShell）

在源工程执行 `npm ci`、`npm run build`，后者包含 `vue-tsc` 类型检查。

在 `opencode/packages/app-cmcc` 执行：

```powershell
$env:LANDING_DIR = (Resolve-Path '../../../product-statspanel').Path
bun run ./scripts/sync-landing.ts --skip-build
bun run build
$env:PLAYWRIGHT_CHANNEL = 'chrome'
bun x playwright test --config e2e/landing/playwright.config.ts
```

显式设置 `LANDING_DIR`，避免原同步脚本默认目录名使用特殊连字符而与本机普通连字符目录不一致。
同步脚本会替换生成目录，运行前确认其中没有需要保留的手工修改。源工程改动和 opencode 同步产物分别提交。

## 验证边界

定向浏览器测试覆盖桌面/窄屏首屏、视频先于 Vue 发起请求、单次视频下载、视频失败封面、延后预取、滚动加载、图片比例及研究步骤切换，并使用与部署环境一致的关键 CSP 限制。
本地网络模拟只用于比较加载顺序，不能代替部署后的公网首帧耗时验收。服务器带宽、分段请求和静态缓存策略不在本次修改范围内。
